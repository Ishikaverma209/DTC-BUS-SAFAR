🚌 AI Safar – Smart DTC Bus Route & Seat Booking System

AI Safar is a smart public transport system that helps users find bus routes, check seat availability, and book seats in advance. The goal is to make daily commuting easier, faster, and more organized by reducing overcrowding and confusion in buses.

🔹 Features
🗺️ Search bus routes (Source → Destination)
🚌 View available buses on selected route
💺 Check seat availability in real time
🎟️ Book seats in advance
📍 Route-based smart search system
⏱️ Estimated travel time display (mock/logic-based)
👨‍💼 Admin panel to manage buses and seats
🔹 Tech Stack
Frontend: React, Tailwind CSS
Backend: Node.js 
Database: MongoDB / Firebase
Maps: Google Maps API (UI integration)
🔹 Project Goal

The main goal of AI Safar is to improve public transport experience by allowing users to plan their journey in advance, check seat availability, and book seats without last-minute stress or overcrowding issues.

🔹 Future Improvements
📡 Real-time GPS tracking of buses
💳 Online payment integration
📲 Mobile application version
🤖 AI-based crowd prediction
